# Human-Activity-Recognition-using-Smartphone-Sensor-Data
Research Intern at NIT, Jalandhar (June – July 2025)

This project focuses on recognizing human activities (e.g., walking, sitting, standing) using smartphone sensor data. The work was conducted as part of my research internship under faculty mentorship at NIT Jalandhar.

🔹 Project Overview

Built and evaluated multiple classification models for activity recognition, including:

Logistic Regression

Decision Tree

Convolutional Neural Network (CNN)

Performed data preprocessing, cleaning, and exploratory data analysis using NumPy, Pandas, Matplotlib, and Seaborn.

Implemented CNN with TensorFlow & Keras for deep learning-based recognition.

Compared models using metrics such as accuracy, confusion matrix, and ROC curve.

🔹 Tech Stack

Languages: Python

Libraries: NumPy, Pandas, Matplotlib, Seaborn, TensorFlow, Keras, Scikit-learn

Techniques: Machine Learning, Deep Learning, CNN, Data Preprocessing, Model Evaluation

🔹 Key Learnings

Practical experience in applying machine learning and deep learning techniques on real-world sensor datasets.

Improved skills in model selection, evaluation, and performance optimization.

Gained research exposure and mentorship experience at a reputed institute.
